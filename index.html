Sobre

Sou Lucas Retamero Bortoletto, de Americana (SP), e estudo Desenvolvimento de Sistemas. Comecei a programar pelo curso e acabei gostando de entender como as coisas funcionam por dentro, do banco de dados até a tela que o usuário vê.

Hoje trabalho principalmente com desenvolvimento web: PHP e PostgreSQL no back-end, HTML, CSS e JavaScript no front-end. Também já fiz uma API em Node.js e projetos em C++, como um algoritmo genético que manipula as soluções bit a bit.

Meu projeto mais completo é a Lapisari, uma loja virtual de lapiseiras de coleção, que juntou duas coisas de que eu gosto: programação e material de desenho técnico. Meu objetivo é seguir na área de desenvolvimento e continuar aprendendo com projetos reais.
